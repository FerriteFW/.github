# Ferrite

Free firmware for the Radtel RT-950 Pro, source public. 0.9 is the first public release.

## Start here

1. **Get [Ferrite Console](https://github.com/FerriteFW/console/releases/latest)**, the companion app: macOS, Linux or Windows, or [in the browser](https://console.ferritefw.dev).
2. **Connect the radio** with its programming cable.
3. **Open Install.** Console backs up the whole radio first, then installs Ferrite.

Console also updates Ferrite, edits channels and settings, and puts stock back from your backup.

## The projects

- [ferrite](https://github.com/FerriteFW/ferrite): the firmware.
- [console](https://github.com/FerriteFW/console): Ferrite Console, to install, update and program the radio.
- [docs](https://github.com/FerriteFW/docs): the manual.
- [website](https://github.com/FerriteFW/ferrite-website): ferritefw.dev and the blog.
